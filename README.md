# TEVS.KZ

Официальный сайт юридической практики Тевс Натальи Геннадьевны.

## Ветки репозитория

- `source` — исходный код, тесты и сборка.
- `main` — только готовые файлы для автоматического развертывания в Plesk.

Так исходники и конфигурация проекта не публикуются в document root сайта.

## Готовая версия для хостинга

После команды `npm run build:static` готовая версия создаётся в `static-build/`:

- `index.html`
- `kk/index.html`
- страницы политики конфиденциальности
- `assets/`
- оптимизированные изображения, favicon, `robots.txt`, `sitemap.xml` и `.htaccess`

Ветка `main` формируется из содержимого `static-build/`. Plesk продолжает автоматически публиковать `main` без серверного запуска Node.js.

## Исходники

Основная страница находится в `app/page.tsx`, стили — в `app/globals.css`.

Локальный запуск:

```bash
npm ci
npm run dev
```

Проверка основной сборки:

```bash
npm test
```

Повторная сборка статической версии:

```bash
npm run build:static
```

Требуется Node.js 22.13 или новее.

## Страницы услуг

`/uslugi/` и `/kk/uslugi/` содержат семь направлений. Каждая услуга имеет отдельную русскую и казахскую страницу, связанную с главной, каталогом, соседними услугами и записью на консультацию.

- Тексты и соответствие языков: `scripts/services-content.mjs`.
- Данные практики и метаданные главных страниц: `scripts/site-config.mjs`.
- Генерация HTML, hreflang, JSON-LD и sitemap: `scripts/prerender-static.mjs`.
- Оформление: `app/services.css`.
- Действующие настройки хостинга, аналитики и политики сохранены в `public/`.

После изменения текстов выполните `npm run build:static`, затем `node --test tests/static-output.test.mjs tests/service-pages.test.mjs`. Генератор также допускает повторный запуск после сборки: исходная оболочка Vite сохраняется в `.static-ssr/template.html`.
