# TEVS.KZ

Официальный сайт юридической практики Тевс Натальи Геннадьевны.

## Готовая версия для хостинга

В корне репозитория уже находятся готовые статические файлы:

- `index.html`
- `assets/`
- изображения и favicon

Для обычного статического хостинга достаточно публиковать корень репозитория. Команда сборки и серверный запуск не требуются.

## Исходники

Основная страница находится в `app/page.tsx`, стили — в `app/globals.css`.

Локальный запуск:

```bash
npm ci
npm run dev
```

Проверка основной сборки:

```bash
npm test
```

Повторная сборка статической версии:

```bash
npm run build:static
cp -a static-build/. .
```

Требуется Node.js 22.13 или новее.
